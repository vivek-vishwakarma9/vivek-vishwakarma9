## 🚀 Executive Summary

Enterprise-focused **DevOps & DevSecOps Cloud Engineer** with extensive experience architecting, automating, and securing scalable multi-cloud infrastructures on **Microsoft Azure** and **AWS**. 

- ☁️ **Multi-Cloud Architecture:** Designing highly available, fault-tolerant landing zones across **Azure & AWS** with strict Zero-Trust boundaries.
- ☸️ **Container Orchestration:** Operating enterprise-scale **Kubernetes (AKS / EKS)**, Web Apps, and microservices platforms with **Zero-Downtime deployments** (`ReadWriteMany` CSI storage, HPA, and Service Mesh).
- 🛡️ **Shift-Left DevSecOps:** Embedding automated enterprise security scanning (**SAST, DAST, SCA, Container Security**) directly into CI/CD pipelines via **Checkmarx, Black Duck, Aqua Security, Trivy, Snyk, SonarQube, and Checkov**.
- ⚙️ **Infrastructure as Code (IaC):** 100% modular infrastructure automation using **Terraform, Terragrunt, and Ansible** with automated state-lock recovery and continuous daily drift governance.
- 📈 **Full-Stack Observability:** End-to-end monitoring, distributed tracing, and APM telemetry using **Datadog, Dynatrace, Prometheus, and Grafana**.
